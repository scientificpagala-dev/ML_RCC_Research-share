How to use this set

  1. 01

    Start with Sheet 01 — read the reality check before trusting any status claim, including this page's.

  2. 02

    Work Sheet 03's four required projects while skimming Sheet 04 for what each one is building toward.

  3. 03

    Once prepared, follow Sheet 02 phase by phase — its checklist is the actual critical path.

  4. 04

    Prep Project 05 and Skill Domain 09 (both Abaqus) are bonus — skip them for zero cost to the research, or slot Project 05 in after Project 01 if there's spare time.

  5. 05

    Checkboxes are per-session only — they reset on reload. Each sheet is a working-session tool, not a permanent tracker.
