Sheet 03 / 04 — Preparation Workbook

Four Small Projects
Before One Big One

The main campaign is 80 buildings × ~35 ground motions × 16 intensity levels run all at once. That is a brutal place to debug a convergence error or a data-leakage bug for the first time. Each project below isolates one subsystem — structural scripting, nonlinear dynamics, ML, and writing/statistics — at a scale small enough to fully understand before it has to work unattended for 8 hours.

Preparation Project 05 · Cross-tool verification (optional)

Second Tool, Same Building

Rebuild the exact same 3-storey, 1-bay frame from Project 01 in Abaqus/CAE, using the Concrete Damaged Plasticity (CDP) model instead of fiber sections, and compare period and pushover capacity against the OpenSeesPy version. Won't appear anywhere in the paper — it's here because watching two structurally different modelling approaches agree, or not, on the same building is one of the fastest ways to stress-test your own understanding of both.

~1.5–2 weeks · optional
Difficulty
DeliverableAn Abaqus/CAE model of the same frame — a frequency step for T1, and a displacement-controlled static pushover producing a base-shear-vs-roof-drift curve — plus a short note comparing both against the OpenSeesPy results.
